# ATLAS FSM Implementation Plan

**Goal:** Implement a 7-state FSM that drives the ATLAS turret to autonomously
track and intercept a ballistic projectile in Webots, satisfying the Embedded
Intelligence specialisation requirements (sensor fusion, context-aware behaviour,
real-time logic).

**Design spec:** All interfaces are defined as Python stubs with docstrings in
`controllers/atlas_controller/`. Review those files before implementing.

**ADRs:** `docs/adr/` — 0001 (fixed lookahead), 0002 (Kalman filter),
0003 (continuous fusion), 0004 (sensors simulated), 0005 (filterpy).

---

## Architecture

```
SearchRadar ──────────────────────────────────► FSM (SEARCH/ACQUIRE: get_detections)
FCR ──────────────────────────────────────────► FSM (ACQUIRE: set_target)
                │                                         │
                ▼                                         ▼
          TrackFilter (Kalman) ◄──── both sensors update every timestep
                │
                ├──► FSM (TRACK+: get_position, get_velocity)
                │
                └──► BallisticTrajectoryPredictor ──► FSM (PREDICT: get_intercept)
```

**Main loop order (atlas_controller.py):**
1. `search_radar.update()`, `fcr.update()`
2. `track_filter.predict()`
3. `track_filter.update_fcr(...)`, `track_filter.update_search(...)`
4. `fsm.step()`
5. Projectile reset logic (independent of FSM)

## Tasks

### Task 0: Dependencies
- Add `filterpy>=1.4` and `numpy>=1.26` to `pyproject.toml` ✓ (done)
- Run `uv sync` ✓ (done)

### Task 1: Test infrastructure
- Create `tests/__init__.py`
- Create `tests/stubs.py` with:
  - `StubProjectile(positions)` — returns pre-defined position sequence
  - `StubMotor()` — records last `setPosition()` call
  - `StubFCR(position, noise_std)` — returns fixed position, no-op update
  - `StubSearchRadar(detections)` — returns fixed detection list
  - `StubTrackFilter(position, velocity)` — returns fixed state, no-op predict/update

### Task 2: FireControlRadar
- Write tests in `tests/test_fcr.py` first (TDD)
- Implement `fire_control_radar.py` to pass tests
- Key behaviours to test: turret subtraction, noise injection, None before first update, set_target clears last position

### Task 3: SearchRadar
- Write tests in `tests/test_search_radar.py` first
- Implement `search_radar.py` to pass tests
- Key behaviours: get_detections returns list, noise applied, set_target filters to one node, None before set_target

### Task 4: TrackFilter
- Write tests in `tests/test_track_filter.py` first
- Implement `track_filter.py` using filterpy
- Key behaviours: predict propagates state, update_fcr/update_search fuse with correct R, reset clears state, is_initialised gates on first update
- Kalman matrices to verify: F (with gravity control input), H (position observation), R_fcr vs R_search diagonal scaling

### Task 5: BallisticTrajectoryPredictor
- Write tests in `tests/test_ballistic_predictor.py` first
- Implement `ballistic_trajectory_predictor.py`
- Key behaviours: horizontal axes linear extrapolation, Z axis parabolic (gravity), correct scaling with timestep

### Task 6: FSM skeleton — SEARCH and ACQUIRE
- Implement `fsm.py` `__init__`, `step()`, `_do_search()`, `_do_acquire()`
- ACQUIRE calls `fcr.set_target()`, `search_radar.set_target()`, `track_filter.reset()`
- Tests: initial state is SEARCH, SEARCH oscillates pan motor, ACQUIRE transitions to TRACK after lock

### Task 7: FSM — TRACK and PREDICT
- Implement `_do_track()`, `_do_predict()`
- TRACK: follows `track_filter.get_position()`, counts frames, transitions to PREDICT
- PREDICT: calls `ballistic_predictor.get_intercept()`, validates intercept above ground
- Tests: frame counter increments, transition to PREDICT after MIN_TRACK_FRAMES, invalid intercept returns to TRACK

### Task 8: FSM — AIMING, ENGAGING, RESET
- Implement `_do_aim()`, `_do_engage()`, `_do_reset()`
- ENGAGING sets `laser_active = True`
- RESET clears all state and returns to SEARCH
- Tests: motor positions set at AIMING, laser active at ENGAGING, RESET clears everything

### Task 9: Wire into atlas_controller.py
- Rewrite main loop following the order in the Architecture section above
- Delete `radar_system.py`
- Verify full FSM cycle in Webots console

## Definition of Done

- All tests pass (`uv run pytest tests/ -v`)
- Webots console shows all 7 states cycling: SEARCH → ACQUIRE → TRACK → PREDICT → AIMING → ENGAGING → RESET → SEARCH
- `laser_active` toggles True during ENGAGING
- Turret visibly leads the projectile (aims ahead of current position)
